## COSMIC Desktop

This is a **Light** theme, so it goes in COSMIC's Light slot:

Settings → Desktop → Appearance → **Light** → **Import** → `cosmic/TokyoDay.ron`

Accent is blue ![#2959AA](https://placehold.co/12x12/2959aa/2959aa.png) `#2959AA`; the window hint border is the same blue, matching
the dark half.
Use the `+` control if you want a custom swatch.

Frosted glass is on in the `.ron` at `frosted: Low` with an opacity table of
0.66 to 0.96, tinted with the palette's middle neutral ![#898EA0](https://placehold.co/12x12/898ea0/898ea0.png) `#898EA0`, for windows, panel,
applets and system UI (maximized apps stay solid), and corners are squared
(`radius_*: 2.0`), the same as the DarkGold baseline. Adjust frosted glass on
Appearance → Style → Frosted glass after import; those sliders survive a theme switch.

**Known COSMIC bug:** moving the frosted glass opacity / thickness sliders can
reset `text_tint` to ![#FFFFFF](https://placehold.co/12x12/ffffff/ffffff.png) `#FFFFFF`, which on a light theme makes every label
unreadable. If your text turns white, re-import `cosmic/TokyoDay.ron`: it
carries the ink tint and the whole frosted block, so one import restores both.
Upstream fix proposed in [libcosmic#1450](https://github.com/pop-os/libcosmic/pull/1450),
not merged.

Export from Appearance if you tweak backgrounds / tints so you do not lose them.

Pairing tip: import `TokyoNight.ron` from
[cosmic-tokyonight-theme](https://github.com/atraxsrc/cosmic-tokyonight-theme) into the
Dark slot and COSMIC's Dark / Light toggle flips between the two. Wallpaper,
Firefox and the shell layer do not follow the toggle; those are per-rice files.

### Baseline settings

`cosmic/config/` holds the settings that make up the look and rarely change
(panel, dock, applets and shortcuts are left out on purpose):

| Where | Setting |
|-------|---------|
| Fonts | Interface `Maple Mono Normal`, monospace `Maple Mono Normal NFM` |
| Icons | Cosmic-TokyoDay-Blue |
| Windows | Minimize / maximize buttons hidden, theme applied to GNOME apps |
| Terminal | Maple Mono 15 (weights 500 / bold 800 / dim 300), opaque, no header bar, Tokyo Day (light scheme) |

Install the [Maple fonts](https://github.com/subframe7536/maple-font/releases)
(Maple Mono Normal and Maple Mono Normal NFM) and the Cosmic-TokyoDay icons (see
Icons below) and import the terminal scheme first, then:

```bash
./cosmic/install.sh
```

It backs up each file it replaces to `*.bak` and COSMIC applies it live.

## COSMIC Terminal

The desktop `.ron` does not colour ANSI text.

1. COSMIC Terminal → **View → Color schemes…** (not Settings → Appearance)
2. **Light** tab → **Import** → `cosmic-term/TokyoDay-term.ron`
3. View → Settings → Appearance → Color scheme (light) → **Tokyo Day**

If a profile is set as default, set the scheme on that profile too or the
dropdown will look like it did nothing.

Ink text on an opaque pane ![#D6D8DF](https://placehold.co/12x12/d6d8df/d6d8df.png) `#D6D8DF`, a step darker than the desktop; red for
errors, green for strings and success, yellow in its own slot, blue for
commands and directories, cyan for symlinks, purple for magenta. Bright colours
are deeper, dim colours lighter, so bold and dim still read on a light
background. On the pane yellow, purple, cyan and the number colour land between
3.9 and 4.4:1, a little under the 4.5:1 the window background keeps; drop the
`background` line from the scheme to get the window colour back.

If ink is not the plain text you want, there are five other variants
with the same ANSI colours, from Slate ![#5F616D](https://placehold.co/12x12/5f616d/5f616d.png) `#5F616D` to
Storm ![#4F566F](https://placehold.co/12x12/4f566f/4f566f.png) `#4F566F`. Previews and which to
pick: [`cosmic-term/README.md`](cosmic-term/README.md).

## Firefox

Two layers:

1. **Theme (colours):** install
   **[cosmic-tokyoday-theme on addons.mozilla.org](https://addons.mozilla.org/en-US/firefox/addon/cosmic-tokyoday-theme/)**.
   This is the main look.
2. **Stylesheets (optional):** `firefox/chrome/` adds rounded corners, blue
   menu hover, blue accents and blank new-tab tiles on top of the add-on
   (they also work with Firefox's built-in Light theme):

```bash
./firefox/install.sh
```

Fully quit Firefox afterward. Details and CSS rules: [`firefox/README.md`](firefox/README.md).

## Brave

`brave/theme` is a Chromium theme with the Firefox theme's colours: lavender-grey
frame, grey toolbar, green icons and inactive tabs, blue on the active tab.
Brave, Chrome, Chromium and Edge take it, and it loads straight from the
clone, so no Chrome Web Store or Google account is needed:

`brave://extensions` → **Developer mode** → **Load unpacked** → `brave/theme`

Leave the clone in place, Brave keeps reading the folder. Colours, limits and
packing a `.crx`: [`brave/README.md`](brave/README.md).

## Claude Desktop

For the unofficial [claude-desktop-extra](https://github.com/patrickjaja/claude-desktop-extra)
Linux build. `claude-desktop/cosmic-tokyo-night.jsonc` is one theme with both halves:
Tokyo Night in dark mode and Tokyo Day in light mode, so Claude's own
Settings → Appearance toggle switches between the two rices.
Colours come from `cosmic/*.ron`, contrast-checked (text and button text
4.5:1, accents 3:1).

```bash
./claude-desktop/install.sh
```

It copies the file into `~/.config/Claude/themes.d/`. Then press
<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> in Claude Desktop and pick **cosmic-tokyo-night**.

The same file ships in [`cosmic-tokyonight-theme`](https://github.com/atraxsrc/cosmic-tokyonight-theme),
so installing from either repo gives the same theme.

## Cursor editor

`vscode/` is a colour theme extension for [Cursor](https://cursor.com) with
both halves of the pair: **Cosmic Tokyo Night** and **Cosmic Tokyo Day**. It is a plain
VS Code theme extension, so VS Code and VSCodium take it too, and the same
folder ships in cosmic-tokyonight-theme. Code is coloured the way Neovim is in
each rice; the workbench takes the desktop's window and container colours,
with the accent on the active tab, buttons and menu highlight, and the
integrated terminal uses the COSMIC Terminal scheme. Cursor builds its Agent
and chat panels from the same theme colours, so they follow along.

```bash
./vscode/install.sh
```

It packs `vscode/` into a `.vsix` and installs it with
`cursor --install-extension`; run it again after editing the theme. Then press
<kbd>Ctrl</kbd>+<kbd>K</kbd> <kbd>Ctrl</kbd>+<kbd>T</kbd> in Cursor and pick
**Cosmic Tokyo Day**. Three lines in Cursor's `settings.json` make it follow
COSMIC's Dark / Light toggle between Tokyo Night and Tokyo Day; they, the colours and
the contrast notes are in [`vscode/README.md`](vscode/README.md).

## Telegram

`telegram/cosmic-tokyoday.tdesktop-theme` is a Telegram Desktop theme:
lavender-grey chat list and background, mist incoming and pale-green outgoing
bubbles, blue for the accent, links, unread badges and buttons (with
lavender-grey text on them), green for online status and read ticks. Group
member names use the rice's terminal colours. Text and badge colours are
contrast-checked at 4.5:1 or better, except disabled menu items.

Settings → Chat Settings → Chat wallpaper → **Choose from file** →
`telegram/cosmic-tokyoday.tdesktop-theme` → **Apply this theme**.

The colours live in `telegram/colors.tdesktop-theme`, which is plain text;
`build.sh` zips it with the chat background into the `.tdesktop-theme`. The
background is the plain window colour; to put a wallpaper behind the chat instead
(ImageMagick re-encodes it to a 2560px JPEG, Telegram caps theme files at 5 MB):

```bash
./telegram/build.sh --wallpaper backgrounds/tokyoday-anime.png
```

Built against Telegram Desktop 7.3.1. Calls, group calls, statistics charts and
premium badges keep Telegram's own colours.

Telegram has no dark / light pairing, so Tokyo Night, the dark half, ships its
own theme.

## GTK and Qt apps

COSMIC colours GTK apps itself when Appearance → **Apply theme to GNOME apps**
is on (the baseline config turns it on). `gtk/tokyoday.css` is the same palette
pinned by hand for GTK 3 and GTK 4 / libadwaita apps: windows and lists on
![#E6E7ED](https://placehold.co/12x12/e6e7ed/e6e7ed.png) `#E6E7ED`, cards, popovers and dialogs on ![#DEE0E6](https://placehold.co/12x12/dee0e6/dee0e6.png) `#DEE0E6`, text in ![#343B59](https://placehold.co/12x12/343b59/343b59.png) `#343B59`, selection
and accent in ![#2959AA](https://placehold.co/12x12/2959aa/2959aa.png) `#2959AA` with ![#E6E7ED](https://placehold.co/12x12/e6e7ed/e6e7ed.png) `#E6E7ED` text on it, ![#33635C](https://placehold.co/12x12/33635c/33635c.png) `#33635C` for
success and ![#8F5E15](https://placehold.co/12x12/8f5e15/8f5e15.png) `#8F5E15` for warnings. It only sets the named colours, so
widgets keep their stock shapes, and it also works where COSMIC's toggle does
not reach (another desktop, Flatpak apps given access to `~/.config/gtk-4.0`).

```bash
./gtk/install.sh
```

It copies the file to `~/.config/gtk-3.0/` and `~/.config/gtk-4.0/` and adds
`@import url("tokyoday.css");` to `gtk.css` there, after COSMIC's own import so
these colours win (backup in `gtk.css.bak`); another rice's import is
commented out. Restart GTK apps.

`qt/TokyoDay.conf` is a colour scheme for [qt5ct](https://github.com/desktop-app/qt5ct)
/ [qt6ct](https://github.com/trialuser02/qt6ct): windows on ![#E6E7ED](https://placehold.co/12x12/e6e7ed/e6e7ed.png) `#E6E7ED`, text
fields and lists on ![#E6E7ED](https://placehold.co/12x12/e6e7ed/e6e7ed.png) `#E6E7ED`, buttons and tooltips on ![#DEE0E6](https://placehold.co/12x12/dee0e6/dee0e6.png) `#DEE0E6`, text in
![#343B59](https://placehold.co/12x12/343b59/343b59.png) `#343B59`, ![#2959AA](https://placehold.co/12x12/2959aa/2959aa.png) `#2959AA` for the highlight and links, placeholders in ![#707280](https://placehold.co/12x12/707280/707280.png) `#707280`,
disabled text in ![#888B94](https://placehold.co/12x12/888b94/888b94.png) `#888B94`.

```bash
./qt/install.sh
# qt6ct → Appearance → Color scheme → TokyoDay, Palette: Custom → Apply
```

Qt apps read it with `QT_QPA_PLATFORMTHEME=qt6ct` (or `qt5ct`) in the
environment; `~/.config/environment.d/` or your `~/.zshrc` is the place.

Text and secondary text read at 4.5:1 or better on the window, container and
field colours; disabled, placeholder and dim text, like comments elsewhere in
the rice, at 2.6:1.

## Obsidian

`obsidian/cosmic-tokyo-night.css` is a CSS snippet with both halves of the pair:

(![#2959AA](https://placehold.co/12x12/2959aa/2959aa.png) `#2959AA` / ![#2959AA](https://placehold.co/12x12/2959aa/2959aa.png) `#2959AA` / ![#006C86](https://placehold.co/12x12/006c86/006c86.png) `#006C86`), code and checkboxes in ![#385F0D](https://placehold.co/12x12/385f0d/385f0d.png) `#385F0D`, tags

## Cursor

**Oxygen** cursors recoloured to the icon colours, one per folder colour of the
Cosmic-TokyoDay icon pack: **Blue** (default), **Purple**, **Green**, **Ink**. Patched with the cursor
names COSMIC apps ask for. COSMIC has no cursor picker yet, so the script sets it:

```bash
./cursors/install.sh                      # Blue
./cursors/install.sh --variant Purple    # or another, see --list
reboot
```

Previews, what the script touches, how to undo it and how the colours are made:
[`cursors/README.md`](cursors/README.md).

## Terminal extras

Need a [Nerd Font](https://www.nerdfonts.com/) in the terminal for the icons

### kitty, Alacritty, WezTerm, Ghostty

The COSMIC Terminal scheme for other terminals, one file each with the same
sixteen ANSI colours, text in ![#343B59](https://placehold.co/12x12/343b59/343b59.png) `#343B59`, the cursor in ![#2959AA](https://placehold.co/12x12/2959aa/2959aa.png) `#2959AA` and the
selection on ![#B6B9C1](https://placehold.co/12x12/b6b9c1/b6b9c1.png) `#B6B9C1`. Each installer copies the file next to that terminal's
config and backs up what it replaces; the one include line you add is
printed, and is in the comment at the top of each file:

```bash
./kitty/install.sh        # ~/.config/kitty/themes/TokyoDay.conf       kitty.conf:     include themes/TokyoDay.conf
./alacritty/install.sh    # ~/.config/alacritty/themes/tokyoday.toml   alacritty.toml: [general] import = ["~/.config/alacritty/themes/tokyoday.toml"]
./wezterm/install.sh      # ~/.config/wezterm/tokyoday.lua             wezterm.lua:    config.colors = require("tokyoday")
./ghostty/install.sh      # ~/.config/ghostty/themes/TokyoDay          config:         theme = TokyoDay
```

Ghostty and WezTerm can follow COSMIC's Dark / Light toggle once the Tokyo Night
half is installed from its repo as well: `theme = dark:TokyoNight,light:TokyoDay` in
Ghostty, and in WezTerm

```lua
local dark = (wezterm.gui and wezterm.gui.get_appearance() or "Dark"):find("Dark")
config.colors = require(dark and "tokyonight" or "tokyoday")
```

kitty and Alacritty have no such switch; include the other file instead.

`delta/tokyoday.gitconfig` colours [delta](https://github.com/dandavison/delta),

file names in ![#2959AA](https://placehold.co/12x12/2959aa/2959aa.png) `#2959AA`, commit hashes in ![#8F5E15](https://placehold.co/12x12/8f5e15/8f5e15.png) `#8F5E15`, hunk headers in


```ini
    path = ~/.config/delta/tokyoday.gitconfig
[core]
    pager = delta
[interactive]
    diffFilter = delta --color-only
```

### zsh

`zsh/tokyoday.zsh` is the rice part of the shell only: `LS_COLORS` (also used
by lsd for file names and by the completion menu), blue / green / red colours
for zsh-autosuggestions and zsh-syntax-highlighting, lsd / bat / nvim aliases,
the lazygit theme file and the starship prompt. Your own `~/.zshrc` stays private and sources it.

Needs zsh + [oh-my-zsh](https://ohmyz.sh/). `install.sh` clones the two
plugins if missing and appends one `source` line to `~/.zshrc` (backup in
`~/.zshrc.bak`):

```bash
./zsh/install.sh
exec zsh
```

In `~/.zshrc` keep `ZSH_THEME=""` and
`plugins=(git sudo zsh-autosuggestions zsh-syntax-highlighting)`.

## Switching rice

The installers replace what they own (with a `*.bak` copy), but some things
pile up instead: shell layers in `~/.zshrc`, LazyVim specs, the updater link and
btop's theme setting. `scripts/switch.sh` makes Tokyo Day the active rice, coming
from any other `cosmic-*-theme` rice, and tidies those up. Every rice repo ships
the same script.

```bash
./scripts/switch.sh               # switch, icons included
./scripts/switch.sh --keep-icons  # leave the current icon theme alone
```

It backs up every file it replaces, then:

- copies `cosmic/config/` (fonts, terminal look, icons) and turns light mode on.
  The terminal scheme and icon theme are only replaced when the current one is
  not already a Tokyo Day variant, so a dimmer text variant or another icon colour
  survives. Icons stay as they are until `./icons/install.sh` has run.
- runs the fastfetch, lsd, bat, starship, delta, lazygit, kitty, Alacritty,
  WezTerm, Ghostty, Helix, GTK, Qt, Discord, Neovim and Claude Desktop
  installers and sets btop's `color_theme`. The terminal, editor and Qt
  installers only copy theme files; the include line you added once stays,
  switch it by hand when the file name differs between rices
- moves every other rice's LazyVim spec from `~/.config/nvim/lua/plugins/` to
  `~/.config/nvim/rice-off/` (LazyVim loads every spec there and the last
  colorscheme wins); your own specs stay
- comments out every other rice's `source` line in `~/.zshrc`, and
  cosmic-ricing's `ricing/zsh/colors.zsh`, then uncomments Tokyo Day's or adds it
- points `~/update_system.sh` at this repo's updater
- installs the Firefox userChrome / userContent

The GUI steps it cannot do are printed at the end:

1. Settings → Desktop → Appearance → Light → Import `cosmic/TokyoDay.ron`
2. COSMIC Terminal → View → Color schemes → Light tab → Import `cosmic-term/TokyoDay-term.ron`
3. Firefox: disable the old rice's add-on, enable [this one](https://addons.mozilla.org/en-US/firefox/addon/cosmic-tokyoday-theme/), restart Firefox
4. Settings → Wallpaper → a file from `backgrounds/`
5. Claude Desktop: Ctrl+Shift+T → `cosmic-tokyo-night`, Appearance → Light
6. `exec zsh`, restart Neovim (`:Lazy clean` drops plugins only the old specs used)
7. Obsidian: `./obsidian/install.sh <vault>`; delta: the `[include]` path in `~/.gitconfig`

Skip 1 and 2 when that slot already holds Tokyo Day. The first time on this rice,
run [Setup](#setup) once for the fonts, icons and cursor.

**Within the pair** (Tokyo Day ↔ [Tokyo Night](https://github.com/atraxsrc/cosmic-tokyonight-theme)): the two halves
sit side by side in COSMIC's Dark and Light slots and share one Claude Desktop
theme, so after the first time only the Firefox add-on and the wallpaper are
left by hand. Add `--keep-icons` to keep one icon colour across the pair.

Leaving Tokyo Day is the next rice's `./scripts/switch.sh`. `./cursors/uninstall.sh`
puts the Pop cursor back.
